# Brand logos

Drop the transparent PNG (or SVG) logo files here with these EXACT names so the
site picks them up automatically. Until a file is present, the site shows a
clean text fallback instead of a broken image — so nothing looks broken.

| File name                          | Used in | Shows                                         |
| ---------------------------------- | ------- | --------------------------------------------- |
| `lab-logo.png`                     | Header  | Laboratory for Surgical and Metabolic Research |
| `mass-general-brigham.png`         | Footer  | Mass General Brigham                          |
| `harvard-medical-school.png`       | Footer  | Harvard Medical School                        |

Guidelines:
- Use the transparent-background versions.
- Header logo renders ~40–44px tall; a PNG ~2–3x that height (e.g. 120px) looks crisp on retina. SVG is ideal.
- Footer logos render ~28–32px tall.
- Keep file sizes small (<150KB each).
